# USDT شام

منصة تداول ند للند في سوريا: USDT مقابل الليرة السورية والدولار عبر شام كاش. موقع + بوت تلغرام.

## التشغيل

```bash
cd backend && npm install
cd ../frontend && npm install
```

```bash
node backend/server.js
```

```bash
npm run dev --prefix frontend
```

## الدخول

حساب حقيقي فقط: اسم مستخدم وكلمة مرور من الموقع، أو افتح المنصة من زر التطبيق داخل البوت.
